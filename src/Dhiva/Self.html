UseState

  • useState is a React Hook that allows you to add state to functional components.
  • The first element in the array is the current value of the state.
  • The second element is a function used to update the state.
  • The initial value is the starting value for the state.
  • You can use useState for many purposes, such as counting values — like incrementing or decrementing a number.
  • "I used useState to create a counter. When the user clicks a button, the value increases or decreases using the update function."

UseEffect

  • useEffect is a React Hook that allows you to perform side effects in functional components.
  • acts as a combination of componentDidMount,componentDidUpdate,componentWillUnmount
  • No dependancy in the array Runs after every render
  • Empty dependancy in the array([]) :Runs only once after the first render
  • "I used useEffect to fetch user data from an API when the component first loads. The effect runs only once because I passed an empty dependency array."

UseContext

  • useContext is a React Hook that allows you to access values from a Context in a functional component
  • useContext takes a Context object (created by React.createContext) as an argument.
  • It returns the current value of the Context.
  • You can use useContext to share data (like theme, user info, language, etc.) between components — without prop drilling.
  • "I used useContext to access user data from the UserContext. It helps me get the current user’s info in any component without passing props."

UseMemo

  • useMemo is a React Hook that allows you to optimize performance by memorizing the result of a calculation.
  • The first argument is a function that returns a computed value.
  • The second argument is a dependency array — when the values in this array change, the function will re-run.
  • You can use useMemo to avoid unnecessary recalculations, especially for complex operations or heavy functions.
  • "I used useMemo to calculate a filtered list. When the user types in a search box, the list is filtered. But the calculation only runs if the data or search keyword changes."

UseCallback

  • useMemo is used to memoize the filteredList.
  • It only recalculates when data or search changes.
  • This improves performance if data is large or filtering is expensive.

UseReducer
